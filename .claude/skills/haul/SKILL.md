# Running a Haul

Read `docs/PLAYBOOK.md` and follow it: it is the order of work, the bar every item must clear (the
editor's take, the passage with force, a specific picture, three to six cited machine notes in at
least three angles, cards, ideas, a thread to the rest) and how to add the machine's own notes from
sources the Desk fetches. Payloads and credentials are in `docs/EDITORIAL.md`; the CLI's commands are
in `npm run editorial -- --help`.

Never reword the editor's words; never publish without the editor's "approved" for that edition in
this session; never write to D1 or the public bucket except through the CLI.
